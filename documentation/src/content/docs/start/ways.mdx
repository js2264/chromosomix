## Which one?

| You want… | Use |
| --- | --- |
| to look at a map now | [the web app](https://chromosomix.app/) |
| an icon in your dock, and to work offline | [the installed app](/start/where-to-run/#install-it-as-an-app) or [the desktop app](/start/where-to-run/#the-desktop-app) |
| data on a machine with no network | [one HTML file](/start/where-to-run/#one-html-file) |
| a link in a paper that draws the same picture in five years | [a fixed release](/start/where-to-run/#pinned-releases) |
| a live map on your lab's site | [an iframe](/embed/web-page/) |
| the app at your own address, as on an intranet | [your own copy](/advanced/self-hosting/) |
| a map in a notebook or a report | the widget for [Python](/embed/jupyter/) or [R](/embed/r/) |
| the analyses in a script or a pipeline | [the command line](/cli/install/) |

The first six are the whole app; the last three put part of it where you work. All of them read your
data where it lives and upload nothing. [Web, desktop or one file](/start/where-to-run/) says what
the web app, the desktop app and the single file can each reach, and how each is updated.
