## Which one?

| You want… | Use |
| --- | --- |
| to look at a map, now | [the web app](https://chromosomix.app/) |
| an icon in your dock, and to work offline | [the installed app](/start/where-to-run/#install-it-as-an-app) or [the desktop app](/start/where-to-run/#the-desktop-app) |
| to open data on a machine with no network | [one HTML file](/start/where-to-run/#one-html-file) |
| a link in a paper that will draw the same picture in five years | [a fixed release](/start/where-to-run/#pinned-releases) |
| a live map on your lab's site | [an iframe](/embed/web-page/) |
| the app served from your own address, as on an intranet | [your own copy](/advanced/self-hosting/) |
| a map in a notebook or a report | the widget for [Python](/embed/jupyter/) or [R](/embed/r/) |
| the analyses in a script or a pipeline | [the command line](/cli/install/) |

## The same app everywhere

The first six are the whole app, with its maps, tracks, 3D models, analyses and figures. The last
three put a part of it where you work: a view in a page or a notebook, the analyses in a shell.

In all of them your data is read where it lives, on your own disk or where it is published, and
nothing is uploaded. What the web app, the desktop app and the single file can each reach, and how
each one is updated, is on [Web, desktop or one file](/start/where-to-run/).
