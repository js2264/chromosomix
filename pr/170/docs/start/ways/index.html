Ways to use chromosomix

chromosomix is one app that runs in many places. Not sure? Use the web app.

Open chromosomix.app

Open it

The web appIn any recent browser. Nothing to install, no account.chromosomix.app
Installed as an appThe web app in a window of its own, from your dock, and offline.Address bar → Install
The desktop appFor macOS and Linux, from the releases page..dmg · .AppImage · .deb

Keep a copy

One HTML fileThe whole app in one file. Double-click it: it never uses the network.chromosomix-<tag>.html
A fixed releaseEvery release, kept for good at its own address.chromosomix.app/v/<tag>/
On your own serverThe app is static files: copy them to any web server.npm pack chromosomix

Put it in your work

In a web pageA live map in a lab page, a course or a paper’s supplement.<iframe src=…?embed=1>
In a notebookA widget for Python in Jupyter, and for R in Quarto and Shiny.pip install git+…/chromosomix
From a shellEvery analysis as a command, for scripts and pipelines.npm install -g chromosomix

Which one?

Section titled “Which one?”
You want… Use
to look at a map now the web app
an icon in your dock, and to work offline the installed app or the desktop app
data on a machine with no network one HTML file
a link in a paper that draws the same picture in five years a fixed release
a live map on your lab’s site an iframe
the app at your own address, as on an intranet your own copy
a map in a notebook or a report the widget for Python or R
the analyses in a script or a pipeline the command line

The first six are the whole app; the last three put part of it where you work. All of them read your data where it lives and upload nothing. Web, desktop or one file says what the web app, the desktop app and the single file can each reach, and how each is updated.
